# Manav Events – GenAI Celebration & Event Planner (PromptWars Challenge 05)
Plans weddings, birthdays and community events with Gemini on Vertex AI:
budget breakdown by category, step-by-step timeline, vendor checklists, and personalized themes/decor/activities.
Deploy: `gcloud run deploy manavevents --source . --region us-central1 --allow-unauthenticated`
